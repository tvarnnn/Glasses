# V0.7 — Sustained Streaming Instrumentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instrument the existing, verified Tower frame-receive path (`tower/routes/ws.py`) so a sustained streaming session can be measured — FPS, transport sequence gaps vs. Tower-side drops, Tower processing latency, CPU/RAM utilization, bandwidth, disconnects/reconnects, and session duration — without changing the frame wire protocol or the receive → process → ack control flow itself.

**Architecture:** Add a per-connection `SessionMetrics` object that the existing WebSocket handler feeds after each frame it already processes; log periodic and final summaries in the existing `[Tower][...]` structured-log style. Add a standalone soak-test script that drives sustained synthetic load against a running Tower for local/CI-free validation, and a report template that makes target-vs-measured and source-provenance explicit. No new endpoints, no new wire-protocol fields, no queue/backpressure redesign.

**Tech Stack:** Python 3.12, FastAPI/Starlette WebSockets (existing), `psutil` (new — process CPU/RSS only), `websockets` client library (new, dev-only — soak script).

## Global Constraints

- LAN-only; no auth/encryption/transport changes this milestone (unchanged from V0.5/V0.6).
- Do not implement adaptive streaming (IDLE/TRACKING/HIGH_RATE) — explicitly deferred until after V0.7 measurements exist.
- Do not redesign the `receive → process → ack` loop in `tower/routes/ws.py` or introduce a queue/latest-wins mechanism this milestone — instrumentation only (2026-08-19 resolution, Ambiguity 4).
- Do not add any field to the `frame` or `frame_result` WebSocket JSON messages — no iPhone/protocol changes this milestone (2026-08-19 resolution, Ambiguity 2).
- Do not label any measurement "end-to-end" or "capture latency" — only "Tower-side receive-to-result" or "Tower-side CV processing" latency, since DAT's capture-timestamp semantics are unconfirmed (`07-PLATFORM-CONSTRAINTS.md` Limitation 9, Unresolved Questions).
- Track transport sequence gaps and Tower-side backpressure drops as two separate, never-combined counters (2026-08-19 resolution, Ambiguity 3).
- No GPU instrumentation — the milestone's CV operation (grayscale + mean intensity) is CPU-only (2026-08-19 resolution, Ambiguity 1).
- Frames remain processed in memory only, never written to disk (existing invariant, unchanged).
- Logs/metrics must never contain raw frame bytes — only counts, sizes, and timings (`06-PRIVACY-DATA.md` Logs/Telemetry).
- No new HTTP/WebSocket endpoints — reporting is via existing structured logs plus a human-assembled report, to avoid unrequested scope expansion (Rule 10).
- Every task's changes must leave `tests/test_health.py`, `tests/test_ws.py` (existing tests), `tests/test_ws_frames.py`, and `tests/test_frame_processing.py` passing unmodified — the verified V0.6 path is not being redesigned.

```python
import time
from typing import Callable

import psutil


def _avg(values: list[float]) -> float:
    return sum(values) / len(values) if values else 0.0


class SessionMetrics:
    """Tracks measurements for a single WebSocket connection's frame stream.

    A new instance must be created per connection, never reused across a
    reconnect: a new session is a new observation stream, not a
    continuation of the previous one (07-PLATFORM-CONSTRAINTS.md,
    Limitation 4).

    ``backpressure_drops`` is tracked separately from ``transport_seq_gaps``
    on purpose (2026-08-19 V0.7 planning decision) -- the two have
    different causes (network/link loss vs. a Tower-side drop policy) and
    must never be combined into one number. As of V0.7, no code path
    increments ``backpressure_drops``: the receive -> process -> ack loop
    in tower/routes/ws.py is intentionally left unchanged this milestone,
    so this field will always read 0 until a future milestone adds a real
    drop mechanism.
    """

    SUMMARY_LOG_FRAME_INTERVAL = 150

    def __init__(self, clock: Callable[[], float] = time.perf_counter) -> None:
        self._clock = clock
        self._process = psutil.Process()
        self._process.cpu_percent(interval=None)  # prime the internal baseline
        self.start_time = clock()
        self.last_seq: int | None = None
        self.frames_received = 0
        self.transport_seq_gaps = 0
        self.backpressure_drops = 0
        self.bytes_received = 0
        self._receive_to_result_ms: list[float] = []
        self._cv_processing_ms: list[float] = []

    def record_frame(
        self,
        seq: int,
        byte_count: int,
        receive_to_result_ms: float,
        cv_processing_ms: float,
    ) -> None:
        if self.last_seq is not None and seq > self.last_seq + 1:
            self.transport_seq_gaps += seq - self.last_seq - 1
        self.last_seq = seq
        self.frames_received += 1
        self.bytes_received += byte_count
        self._receive_to_result_ms.append(receive_to_result_ms)
        self._cv_processing_ms.append(cv_processing_ms)

    def should_log_summary(self) -> bool:
        return (
            self.frames_received > 0
            and self.frames_received % self.SUMMARY_LOG_FRAME_INTERVAL == 0
        )

    def snapshot(self) -> dict:
        elapsed_s = max(self._clock() - self.start_time, 1e-9)
        return {
            "session_duration_s": round(elapsed_s, 3),
            "frames_received": self.frames_received,
            "effective_fps": round(self.frames_received / elapsed_s, 2),
            "bytes_received": self.bytes_received,
            "bandwidth_bps": round(self.bytes_received / elapsed_s, 2),
            "transport_seq_gaps": self.transport_seq_gaps,
            "backpressure_drops": self.backpressure_drops,
            "receive_to_result_ms_avg": round(_avg(self._receive_to_result_ms), 3),
            "receive_to_result_ms_max": round(
                max(self._receive_to_result_ms, default=0.0), 3
            ),
            "cv_processing_ms_avg": round(_avg(self._cv_processing_ms), 3),
            "process_cpu_percent": self._process.cpu_percent(interval=None),
            "process_rss_bytes": self._process.memory_info().rss,
        }
```

from datetime import datetime, timezone


class ConnectionTracker:
    """Tracks whether a single tower client (the iPhone) is currently connected."""

    def __init__(self) -> None:
        self._connected_since: datetime | None = None
        self.total_connections = 0
        self.total_disconnects = 0

    def client_connected(self) -> None:
        self._connected_since = datetime.now(timezone.utc)
        self.total_connections += 1

    def client_disconnected(self) -> None:
        self._connected_since = None
        self.total_disconnects += 1

    def is_client_connected(self) -> bool:
        return self._connected_since is not None

    @property
    def connected_since(self) -> datetime | None:
        return self._connected_since

```python
import logging
import time

from fastapi import APIRouter, WebSocket, WebSocketDisconnect

from tower.frame_processing import process_frame
from tower.frames import FrameError, parse_and_decode_frame
from tower.metrics import SessionMetrics

logger = logging.getLogger(__name__)

router = APIRouter()


async def _handle_frame_message(
    websocket: WebSocket, message: dict, metrics: SessionMetrics
) -> None:
    receive_start = time.perf_counter()
    try:
        frame = parse_and_decode_frame(message)
    except FrameError as exc:
        logger.warning("%s", exc)
        return

    logger.info("[Tower][Frame] #%s received: %s bytes", frame.seq, frame.byte_count)
    logger.info(
        "[Tower][Frame] #%s decoded: %sx%s",
        frame.seq,
        frame.decoded_width,
        frame.decoded_height,
    )

    if frame.dimensions_match:
        logger.info("[Tower][Frame] #%s verified", frame.seq)
    else:
        logger.warning(
            "[Tower][Frame] #%s dimension mismatch: declared %sx%s, decoded %sx%s",
            frame.seq,
            frame.declared_width,
            frame.declared_height,
            frame.decoded_width,
            frame.decoded_height,
        )

    result = process_frame(frame.raw_bytes)
    logger.info(
        "[Tower][Frame] #%s processed: mean_intensity=%.2f",
        frame.seq,
        result.mean_intensity,
    )

    receive_to_result_ms = (time.perf_counter() - receive_start) * 1000
    metrics.record_frame(
        seq=frame.seq,
        byte_count=frame.byte_count,
        receive_to_result_ms=receive_to_result_ms,
        cv_processing_ms=result.processing_ms,
    )

    await websocket.send_json(
        {
            "type": "frame_result",
            "seq": frame.seq,
            "mean_intensity": result.mean_intensity,
            "processing_ms": result.processing_ms,
        }
    )

    if metrics.should_log_summary():
        logger.info("[Tower][Session] summary: %s", metrics.snapshot())


@router.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket) -> None:
    session = websocket.app.state.session
    metrics = SessionMetrics()
    await websocket.accept()
    session.client_connected()
    logger.info("client connected")

    try:
        while True:
            message = await websocket.receive_json()
            message_type = message.get("type")

            if message_type == "ping":
                await websocket.send_json({"type": "pong"})
            elif message_type == "frame":
                await _handle_frame_message(websocket, message, metrics)
            else:
                logger.warning("received unknown message type: %s", message_type)
    except WebSocketDisconnect:
        logger.info("client disconnected")
    finally:
        logger.info("[Tower][Session] final summary: %s", metrics.snapshot())
        session.client_disconnected()
```

Note what is deliberately unchanged: the `while True: receive → branch → process → ack` control flow is untouched. No queue, no concurrency, no dropped-frame logic was added — `metrics.record_frame` and the two log calls are the only additions to the hot path, per the Ambiguity 4 resolution (instrumentation-first).

```python
#!/usr/bin/env python3
"""Sustained streaming soak-test client for V0.7 measurement.

Sends synthetic JPEG frames to a running Tower /ws endpoint at a target
FPS/resolution for a configured duration, then prints a Markdown report
combining the roadmap's documented targets with what this script observed
on the *sending* side.

This script cannot see the Tower's own CPU/RAM/backpressure/receive-side
metrics -- those are only visible in the Tower process's own log output
([Tower][Session] final summary: ...). Copy that log line into the printed
report's "Tower-side measured" section by hand.

Requires the `dev` extra: pip install -e ".[dev]"
"""
import argparse
import asyncio
import base64
import io
import json
import time

import websockets
from PIL import Image

ROADMAP_TARGET_WIDTH = 504
ROADMAP_TARGET_HEIGHT = 896
ROADMAP_TARGET_FPS = 15
ROADMAP_TARGET_MIN_MINUTES = 20
ROADMAP_TARGET_MAX_MINUTES = 30

# "synthetic-script": frames generated by this script -- lowest fidelity,
# validates Tower plumbing only. "mock-device-kit"/"iphone-camera": driven
# through the actual iOS app. "physical-glasses": real hardware end to end.
VALID_SOURCES = ("synthetic-script", "mock-device-kit", "iphone-camera", "physical-glasses")


def _make_jpeg_base64(width: int, height: int) -> str:
    buffer = io.BytesIO()
    Image.new("RGB", (width, height), color=(90, 90, 90)).save(buffer, format="JPEG")
    return base64.b64encode(buffer.getvalue()).decode("ascii")


async def run_soak_test(
    uri: str,
    width: int,
    height: int,
    fps: float,
    duration_s: float,
    source: str,
) -> dict:
    frame_data_b64 = _make_jpeg_base64(width, height)
    interval_s = 1.0 / fps
    seq = 0
    frames_sent = 0
    frames_acked = 0
    bytes_sent = 0
    start = time.perf_counter()

    async with websockets.connect(uri) as ws:
        while (time.perf_counter() - start) < duration_s:
            frame_start = time.perf_counter()
            seq += 1
            payload = json.dumps(
                {
                    "type": "frame",
                    "seq": seq,
                    "width": width,
                    "height": height,
                    "format": "jpeg",
                    "data": frame_data_b64,
                }
            )
            await ws.send(payload)
            frames_sent += 1
            bytes_sent += len(payload)

            response = json.loads(await ws.recv())
            if response.get("type") == "frame_result":
                frames_acked += 1

            elapsed = time.perf_counter() - frame_start
            sleep_for = interval_s - elapsed
            if sleep_for > 0:
                await asyncio.sleep(sleep_for)

    elapsed_total = time.perf_counter() - start
    return {
        "source": source,
        "target_width": width,
        "target_height": height,
        "target_fps": fps,
        "requested_duration_s": duration_s,
        "actual_duration_s": round(elapsed_total, 2),
        "frames_sent": frames_sent,
        "frames_acked": frames_acked,
        "achieved_send_fps": round(frames_sent / elapsed_total, 2) if elapsed_total > 0 else 0.0,
        "bytes_sent": bytes_sent,
        "send_bandwidth_bps": round(bytes_sent / elapsed_total, 2) if elapsed_total > 0 else 0.0,
    }


def _print_report(result: dict) -> None:
    print("## V0.7 Sustained Streaming -- Soak Run Report\n")
    print(f"**Source:** {result['source']}\n")
    print("### Target (from 03-ROADMAP.md)")
    print(f"- Resolution: ~{ROADMAP_TARGET_WIDTH}x{ROADMAP_TARGET_HEIGHT}")
    print(f"- FPS: ~{ROADMAP_TARGET_FPS}")
    print(f"- Session duration: {ROADMAP_TARGET_MIN_MINUTES}-{ROADMAP_TARGET_MAX_MINUTES} minutes\n")
    print("### Measured -- client (send) side, this script")
    for key, value in result.items():
        if key == "source":
            continue
        print(f"- {key}: {value}")
    print(
        "\n### Measured -- Tower (receive/process) side\n"
        "Paste the Tower process's own log line here "
        "([Tower][Session] final summary: ...):\n\n"
        "```\n<paste here>\n```\n"
    )
    print(
        "### Manual (not measurable from this script or the Tower)\n"
        "- Battery behavior (iPhone):\n"
        "- Thermal behavior (iPhone/glasses):\n"
        "- Disconnects/anomalies observed during the run:\n"
    )


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--uri", default="ws://127.0.0.1:8000/ws")
    parser.add_argument("--width", type=int, default=ROADMAP_TARGET_WIDTH)
    parser.add_argument("--height", type=int, default=ROADMAP_TARGET_HEIGHT)
    parser.add_argument("--fps", type=float, default=ROADMAP_TARGET_FPS)
    parser.add_argument(
        "--duration-s",
        type=float,
        default=60.0,
        help=(
            "Soak duration in seconds (use e.g. 1200-1800 for the full "
            "20-30 minute roadmap target; defaults to a short 60s smoke run)."
        ),
    )
    parser.add_argument(
        "--source",
        required=True,
        choices=VALID_SOURCES,
        help="What produced the frames sent by this run, so the report cannot be mistaken for a different source.",
    )
    args = parser.parse_args()

    result = asyncio.run(
        run_soak_test(
            uri=args.uri,
            width=args.width,
            height=args.height,
            fps=args.fps,
            duration_s=args.duration_s,
            source=args.source,
        )
    )
    _print_report(result)


if __name__ == "__main__":
    main()
```
