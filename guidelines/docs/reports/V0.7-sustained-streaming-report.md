## Mock/iPhone-camera vs. physical-glasses caveat

Per `07-PLATFORM-CONSTRAINTS.md` Limitation 12: a run whose frame source
above is `synthetic-script` or `mock-device-kit` validates the Tower-side
plumbing (instrumentation correctness, sustained-connection stability)
only. It does **not** establish real-world FPS, bandwidth, latency, or
drop-rate figures — those require `iphone-camera` (for real BLE/WiFi
transport behavior) and ultimately `physical-glasses` (for real optics,
RF, thermal, and battery figures). Label every number above with which
source produced it, and do not present a `synthetic-script` or
`mock-device-kit` run as satisfying V0.7's real target measurement.
